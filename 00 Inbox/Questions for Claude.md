# Questions for Claude

Drop any question here while you study, so you don't have to stop and look it up. Then open a Claude Code session on this repository and say **"answer my questions"**. Claude will:

1. Answer each question from **your own notes first**, linking to them,
2. **Search the web** for anything your notes don't cover, and cite the sources,
3. Write or update the matching topic note in `02 Topics`, and
4. Move the question to **Answered** below with a link to where the answer now lives.

Tip: write the question the way it came up ("why does the cat's heart rate drop under dex?"). Claude will tidy it.
