# Medical Terminology Glossary

> [!tip] Decode, don't memorize
> Almost every medical word is **prefix + root + suffix**. *Ovario-hyster-ectomy* = ovary + uterus + surgical removal = a spay. Learn the parts and you can read words you have never seen.

## Prefixes

| Prefix        | Meaning              | Example                                  |
| ------------- | -------------------- | ---------------------------------------- |
| a- / an-      | without, lack of     | **an**uria (no urine production)         |
| ante- / pre-  | before               | **pre**operative                         |
| anti-         | against              | **anti**emetic (against vomiting)        |
| brady-        | slow                 | **brady**cardia                          |
| tachy-        | fast                 | **tachy**pnea (fast breathing)           |
| dys-          | difficult, painful   | **dys**pnea, **dys**uria                 |
| endo-         | within               | **endo**scope                            |
| epi-          | upon, over           | **epi**dural                             |
| hyper-        | above, too much      | **hyper**thermia                         |
| hypo-         | below, too little    | **hypo**glycemia                         |
| inter-        | between              | **inter**vertebral                       |
| intra-        | within               | **intra**venous                          |
| peri-         | around               | **peri**cardium                          |
| poly-         | many, much           | **poly**uria, **poly**dipsia             |
| post-         | after                | **post**operative                        |
| sub-          | under                | **sub**cutaneous                         |

| -itis      | inflammation                | dermat**itis**                             |
| -logy      | study of                    | cardio**logy**                             |
| -megaly    | enlargement                 | cardio**megaly**                           |
| -oma       | tumor, mass                 | lip**oma**                                 |
| -osis      | abnormal condition          | cyan**osis**                               |
| -ostomy    | surgically created opening  | gastr**ostomy** tube                       |
| -otomy     | incision into               | lapar**otomy**                             |
| -pathy     | disease                     | cardiomyo**pathy**                         |
| -penia     | deficiency                  | thrombocyto**penia**                       |

| -pnea      | breathing                   | a**pnea**                                  |

## Directional terms

| Term                | Meaning                                              |
| ------------------- | ---------------------------------------------------- |
| cranial             | toward the head                                      |
| caudal              | toward the tail                                      |
| rostral             | toward the nose (used on the head only)              |
| dorsal              | toward the back / top line                           |
| ventral             | toward the belly                                     |
| medial              | toward the midline                                   |
| lateral             | away from the midline                                |
| proximal            | closer to the body / point of attachment             |
| distal              | farther from the body                                |
| palmar              | the "sole" of the front paw                          |
| plantar             | the "sole" of the hind paw                           |
| recumbent           | lying down (lateral, sternal, or dorsal recumbency)  |
