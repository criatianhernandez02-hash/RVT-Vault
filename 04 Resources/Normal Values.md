# Normal Values

> [!warning] Ranges differ slightly between textbooks
> The numbers below are the commonly taught ranges. **On exams, use the ranges from your Penn Foster materials**, and update this table to match them as you go. Rows left blank are for you to fill in from your course.

## Vital signs (TPR) — adults at rest

| Species | Temperature                     | Heart rate (bpm) | Respiratory rate (breaths/min) | Notes                                                        |
| ------- | ------------------------------- | ---------------- | ------------------------------ | ------------------------------------------------------------ |
| Dog     | 99.5–102.5 °F (37.5–39.2 °C)    | 60–140           | 10–30                          | Small breeds and puppies run faster; giant breeds slower     |
| Cat     | 100.5–102.5 °F (38.1–39.2 °C)   | 140–220          | 20–30                          | Stress in the clinic pushes HR and RR up                     |
| Horse   |                                 |                  |                                |                                                              |
| Cow     |                                 |                  |                                |                                                              |
| Rabbit  |                                 |                  |                                |                                                              |
| Ferret  |                                 |                  |                                |                                                              |

**Other quick checks (dog and cat):** capillary refill time (CRT) under 2 seconds; mucous membranes pink and moist; skin tent snaps back immediately.
