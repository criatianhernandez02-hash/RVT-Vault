# Courses MOC

Penn Foster's Veterinary Technician A.S. is four semesters, 66 credits, with Externship 1 at the end of semester 2 and Externship 2 at the end of semester 4. The semester outline below is pieced together from Penn Foster's public program pages, so **replace it with the exact course titles from your student portal**, or tell Claude your course list and it will build the folders.

## How courses are organized
- One folder per course inside `01 Courses`, each with its own `<Course> MOC` note linking every lecture.
- Lecture notes use the **Lecture Note** template and are named `<Code> L<nn> - <Title>`, for example `AP1 L03 - Cardiovascular System`. The code keeps names unique across the vault (Obsidian links by filename), and `L<nn>` keeps them in lesson order.
- Facts that outlive the course (how the heart works, what a drug does) belong in `02 Topics`, linked from the lecture. The lecture note is *where you learned it*; the topic note is *what you know*.
